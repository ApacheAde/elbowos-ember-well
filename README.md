# Ember Well

Full-colour Python 3 neon magnet-well arcade for [ElbowOS](https://x.com/ElbowOS).

Catch falling embers in the well with a sliding magnet bucket. Hold Space to pull nearby embers. Dodge ash rocks. Combos pay extra.

## Play

```bash
pip install -r requirements.txt
python3 ember_well.py --play
```

Controls: A/D or arrows to move, Space or Up to pull, Esc to quit.

## Record a 9:16 reel

```bash
python3 ember_well.py --record
```

Writes a 15s 1080x1920 H.264 MP4 (requires ffmpeg).
